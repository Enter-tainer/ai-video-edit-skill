# 选片与结构：判据、数据、真实取舍记录

> 这一份回答两个问题：**哪条素材该进片**，**每段该给多长**。
> 所有数字都是实测值；方法可迁移，**素材编号与地名已抽象化**。

---

## 一、选片

### 1.1 第一原则：AI 评分只做初筛

自动审片给出的 `keep_score` 擅长判断"**有没有明确主体 / 有没有技术缺陷**"，
但**判断不了"这一眼好不好看"**。同一条素材上两个方向都翻过车：

| 素材（描述化） | AI | 人眼 |
|---|---|---|
| 针叶林内部长镜：阳光斑落在苔藓地上 | `keep=2`，issues="主体太远/构图平淡" | **很好看** |
| 阴暗针叶林下山 POV | `keep=2`，issues="欠曝/失焦" | 这一章最有**沉浸感**的一条 |
| 桥 + 路牌的到达镜 | `keep=4`，issues 空 | 桥后是**一大片空碎石滩**，还拍进自己的影子 |

**推论**：AI 打分用来排**硬缺陷**（全黑、对准地面、仪表台占半幅、别人贴脸），
`keep_score ≥ 4` 只当"候选池"。**最终取舍必须抽帧看图。**

第三条值得单独说：模型给 4 分是因为"有没有明确主体"这一项过了，
但**画面里没有值得看的东西** —— 这类"技术上没毛病、内容上空"的镜头，
只能靠真正看帧才能发现。

### 1.2 抽帧联系表（contact sheet）的具体做法

给一串素材号，每条**均匀抽 N 帧**（`t = tin + span*(i+0.5)/n`），拼成一张图：

- 每行 **一条素材**，行首标 `素材号 + 拍摄时间 + 时长`；
- 每格标**这一帧的时间点**（后面写 `seen` 要引用它）；
- 单元 **384×216**（够看构图，又不会让整张图过大）；
- 一次比选 **6–8 条**。

```
python scripts/contact.py --out work/look.png --frames 6 <素材号> <素材号> ...
python scripts/contact.py --out work/car.png  --frames 6 --tin 4 --tout 20 <素材号> ...
python scripts/day_inventory.py <YYYY-MM-DD>        # 先列当天的素材清单
```

**为什么有效**：逐条看原片看不完，但**一张拼图能同时比 6–8 条**，
而且"同一段路的十几条重复镜头"并排一看就分得出哪条干净。

### 1.3 证据字段 `seen`：只有看过帧才说得出的细节

选片结果的字段结构：

```json
{
  "clip": "<素材号>", "tin": 18.0, "tout": 26.0,
  "chapter": "第一章", "role": "情绪长镜",
  "why":  "…取舍理由，含代价与替代方案…",
  "seen": "第 20.5 / 23.5 秒两帧：一地发亮的苔藓上斜切过三到四条树干的长影……",
  "ambience": "keep"
}
```

**为什么 `seen` 是这套流程的核心**：

1. **可独立复核**。另一个 agent 可以按它写的时间点重新抽帧，证实或证伪。实测抓到过：
   一位 agent 写"底部**始终**有一条红褐色横杠横贯全宽"，
   复核发现 **前 7 秒底部只有暗色山脊/植被，横杠第 8 秒才出现** → "始终"不成立。
   同一轮里，它关于另一条车拍镜的两条断言（"白色轿车贴得极近"、
   "黄衣人和深色衣服的人走在车流里"）被**证实**。
2. **挡住"没看图、按评分编理由"**这种最贵的错误。
3. **顺带产生可用信息**：`"26 秒之后画面中央会走进背包同伴"` → 窗口只取 18.0–26.0。

**写法要求**：具体到**时间点 + 可指认的物体/运动/颜色**，不要形容词堆砌。
`why` 里必须写**代价**（"前 2 秒画面左前方有同伴背影，属扣分项，
但他是朝目的地走去的被摄主体、不是挡镜"）——只写好话的 `why` 是没用的。

> ⚠️ **`seen` 证明"看过"，不等于"看准"。** 用 **1:1 放大帧**复核时抓到过四类系统性偏差：
> **事实错误**（说"无人物"其实全程有人）、**方位说反**（左/右）、
> **不完整/过度断言**（漏了人影和建筑）、**差一个量级**（"占画面 1/12"实际是 1/4~1/5）。
> 所以流程必须是 `seen → 独立复核员用放大帧重看 → 才定窗口`。
> 详见 `SKILL.md` §3.2.1，那里有完整的四类偏差对照表和复核的正面/反面的实例。

### 1.9 剪辑点不要卡在动作中间

**规则**：**凡是有动作的镜头，出点必须落在动作完成之后**（宁可多 0.5s）。

**为什么**：实测有一次出点正好卡在同伴**跨河沟的瞬间**，
反馈是"在跳的前一瞬间给它掐断了，很难受"。
这类错误在缩略图和静帧上完全看不出来，**只有看连续帧才会发现**。

**怎么验证**：对每个"有动作"的镜头，在出点前后各抽 3 帧（间隔 0.3s），
确认动作已完成。

### 1.4 "宁长勿碎"：取舍的粒度是段落级，不是单条素材级

**最大的教训**：只是把每条镜头稍微拉长一点 → 正文中位 **7.0s**，与长版的 6.0s
几乎没区别，**"碎"根本没解决**。原因：总时长固定时，单条拉长必然要靠别处补回来。

**正确做法 = 减少镜头数**：

| | 正文镜数 | 正文中位 | ≥8s |
|---|---|---|---|
| 改前 | 15 | 7.0s | 7 |
| **改后** | **12** | **10.0s** | **9** |

拿掉的正是反馈里说的"没啥风景的走路部分"（"走向雪峰" / "林间土路下坡" / "苔藓小径跟拍"）。

**注意"苔藓小径跟拍"这个细节**：它**已经**被 QC 修到了干净窗口
（原窗口画面下缘全是拍摄者自己的手、手套和登山杖），
但这一版**整条撤掉** —— 因为两条"走在路上"连着会**重新变碎**。
**单条素材"够干净"不等于该留下。**

### 1.5 短版本"碎"了怎么修：章内腾挪

短版的每章长度被**配乐槽位**锁死（余量只有 0.6–2.2s），不能靠加时长解决。
做法：按章各减 1 条（短版专用的入出点覆盖**不动长版窗口**），
把省下的秒数加到留下的镜头上。**每章只会变短 → 槽位一定够**。

实测中版正文中位 **5.5s → 8.0s**，总长 3:04 → **2:55**。

### 1.6 两个版本由"选片结果驱动"，不是"从长版删镜头"

从长版删镜头得到的短版必然与长版高度重合。正确做法：让 picker **各自独立逐帧看图**
（先读上一轮的观察记录，再自己抽帧复核），产出独立 picks，分镜直接读它。

实测结果：

| | A 版（主推） | B 版（备选） |
|---|---|---|
| 素材来源 | 一批 A 线素材 | 一批**与长版重叠 0 条**的 B 线素材 |
| 与长版重叠 | — | **0 条** |
| 时长 | 2:33 | 2:28 |

A/B 之间有 2 条重合 —— 两个 picker **独立**挑到同一批好素材，**属正常**，
不需要为了"不重合"把它们拆开。

**必须把"要决策者拍板"的取舍单独写出来**（举例，抽象化）：
- 一条被点名过的素材被否掉：复核确认"画面平，且与已选的两条同一条山沟重复"；
- 一条被点名过的素材**保留**：第一次被判"欠曝到看不出东西"，
  按更宽的窗口**二次复核**后确认可用（拐弯、倒木树根、树缝透光三层）。

### 1.7 "手指/手臂入镜"必须分两类处理

决策者原话：`"shooter's own hand and trekking pole are in frame … 这个是没问题的呀，多有沉浸感！"`

- ✅ **拍摄者自己的手 / 登山杖 / 自拍杆 / 相机挂绳入画 = POV 沉浸感，加分项**：
  不扣分、不排掉、选窗口时也不刻意避开。
- ❌ **真正的缺陷是"别人挡在镜头前"**：同伴后背/后脑勺占画面中心、人群贴脸、路人横穿。

**但有一个例外要注意**：如果自己的手/杖**占满画面下缘**、
把有效画面压得很窄，那就是**取窗口的问题**，不是素材的问题 ——
把窗口从"有手的 6–11s"移到"干净的 0.5–5.5s"即可（**不是判它不可用**）。

### 1.7.1 这条规则教给我们的通用教训：**负向约束会反噬**

这条判据曾经**被写反过**下发给选片员（"手/杖入画 = 缺陷"）。
后果有两个，都值得记住：

1. 它把**一整批**素材几乎全禁掉了（因为"底部有仪表台/有手"在车拍素材里几乎是普遍现象）；
2. 后来决策者纠正说"手入画是多有沉浸感"，还得回头**发更正 + 重改窗口**。

**通用规则**：

> **负向约束要么写清"为什么"，要么写成可判定的量，别写死一个动作。**
>
> - ❌ "不要选仪表台/后视镜/手入画的镜头"（把三类完全不同的东西并列，且不可判定）
> - ✅ "底部连续暗带占画幅 **> 20%** 的不要"（可判定，而且后来发现**所有**车内镜头
>   都落在 9–44% 之间 → 于是正解从"禁用"变成"**统一裁底 18%**"）
> - ✅ "观众看不出画面想表达什么"（对"没东西看"这类**内容**问题的正确表述）

顺带一条：**这条负面教训最后变成了一个全片级功能**——
因为"所有车内镜头底部都有仪表台"是个**共性结论**（需要有人把整类素材逐帧看完才能得出），
正解不是逐条挑"没有仪表台的"，而是给整类镜头统一裁底。
**遇到"普遍存在的瑕疵"，优先想"整批怎么处理"，而不是"挑出例外"。**

### 1.8 没用的素材怎么交代

按原因分四类，写进"素材取舍说明"，决策者才看得懂为什么某天一条都没用：

1. **技术问题**（这次 43 条有明确 issue）；
2. **同质化重复**（最大的一类：同一天同一段路拍了十几条几乎一样的，成片只能留一条）；
3. **整段没进片**（某天的转场素材 0/10，因为决策者说过"开车的镜头不要太多"）；
4. **没有不可替代性**（11 条技术上没毛病，但构图/内容与已用镜头高度重合）。

> ⚠️ 第 4 类要**打折扣**：重挑时发现"AI 说没不可替代性"的两条其实很好（见 §1.1）。
> 所以"没有不可替代性"这个判断在 AI 那里**并不可靠**。

## 二、结构（详略预算）

### 2.1 开场要快切

各版本共用同一套开场结构：

```
钩子长镜（2.5s，不出现人物，零旁白）
  → N 个 1.5s 快切蒙太奇
  → 标题条叠在实拍上（不切黑场）
```

- **标题条叠实拍**，不切黑场；数据做成一行**信息浮层**，
  **不要**全屏数据卡 + 缓推放大（观感"确实廉价"）。
- 骨架上：`开场 → 展开 → 抬升 → 低谷（不剪）→ 高潮（撤解说）→ 收束`。
- 片尾可以有**全片唯一一次黑场落版**。

**开场长度怎么定**（20s 的由来）：
对标片 19–27 分钟，冷开场 30–90s、**占比只有 2–4%**；
按比例套到 5 分钟片就是 6–12s —— 但那点时间**连"标题 + 数字"都塞不进去**。
开场要干三件事：**给第一印象 / 上标题 / 报数字锚点**。
实测 **81s 太慢、30s 仍偏慢、20s 是三件事都能做完的最短长度**；
更短的版本再压到 15s（去掉两个快切与副标题）。

### 2.2 每个章节按"叙事弧"配预算

- **低谷用最长镜头让观众一起熬**（对标原话"低谷不剪，高峰才剪"）：
  这次是 20s / 22s / 22s 三条长镜连着扛。
- **高潮段撤掉一切解说**（纯音乐 + 风，51s 无旁白）。
- **每章结尾用一个稳定空镜收束**。
- **检查手段**：把"各章节实长"排成一行，看**过渡章是否比高潮章还长**——
  这是最常见的结构错误。（历史上出现过一次：过渡章 39.6s 比高潮章 23.6s 还长。）

### 2.3 节奏的反直觉事实

**不是"3 秒一切"**：

- 对标片里 >5s 的镜头占 **63.1%**，"没有 1 秒以下的碎镜"；
- 快切只放**开场、换地形、片尾**三处；
- 口播/独白时**绝不切画面**（有单镜 106s / 191.6s 的极端例子）；
- 平均镜长落在 **5.6–10.2s** 区间都算正常，不必为了"高级感"硬切碎。

### 2.4 转场

- **优先硬切 + 运动匹配**（同方向的行进/摇镜直接接）；
- 章节之间 0.5s 黑场或甩镜；
- **不要滥用叠化**。

### 2.5 照片在结构里的位置

- **不再有"章节封面"这个概念**（决策者原话："没有章节封面这个概念吧，
  就是视频里面夹杂一些我们拍到的照片。所以就是时间顺序。"）：
  章节字幕改成压在**本章第一条视频**上。
- 内容照片**按时间合并进视频之间**（见 SKILL.md T15）。
- **照片很占时长**：短版里 9 张要占 **18s**，所以 A/B 短版只放 4 张。
- 停留 **< 1.8s** 的照片不叠 EXIF（一闪而过看不清）。

### 2.6 配乐槽位表（预算的具体形式）

每章一首、各自自然收尾。**槽位余量必须全部为正**：

| 段 | 需要 | 曲子 | 余 |
|---|---|---|---|
| 开场·标题 | 20.0s | 32.0s | +12.0 |
| 第一章 | 51.7s | 53.6s | +1.9 |
| 第二章 | 86.6s | 87.2s | +0.6 |
| 第三章（低谷） | 40.0s | 42.2s | +2.2 |
| 第四章+片尾 | 109.5s | 109.4s | **−0.1**（靠 1.5s 交叉淡化余量覆盖） |

**槽位的作用**：重挑素材后第一章 52.0s → 51.7s、第三章 42.0s → 40.0s，
都还在槽位内 → **不需要重渲配乐**（省掉一次昂贵操作）。
反过来，**加镜头前先看槽位够不够**。

### 2.7 配乐配方（曲子的客观指标）

按"槽位"配调性/BPM/和弦/音符密度，并**回读验证**：

| 段 | 调性·BPM | 和弦 | 目标密度（音/分） | 实测调性 | 实测密度 |
|---|---|---|---|---|---|
| 开场·标题 | Gm · 62 | i–VI–VII | 20–50 | G:minor ✓ | 33.8 ✓ |
| 第一章 | Bb · 60 | I–vi–IV | 16–35 | Bb:major ✓ | 19.3 ✓ |
| 第二章 | Eb · 88 | I–V–vi–IV | 34–100 | Eb:major ✓ | 61.2 ✓ |
| 第三章（低谷） | Cm · 58 | i–VI | ≈15（最空） | C:minor ✓ | 14.2 ✓ |
| 第四+片尾 | Eb · 84 | I–V–IV–I | 49–61 | Eb:major ✓ | 52.7 ✓ |

- **垫底类音乐的"密度"很低**（16–35 音/分）。最初生成的三首密度是配方的 **4–7 倍**
  （228 / 126 音/分），听起来就是"太满"。
- **走记谱（ABC），不走提示词**：同一段用 style 串写 "Eb major / I-V-IV-I / 49–61 音/分"，
  生成出来是 **G 大调、124 音/分**。
- **必须纯器乐**，双证据检测见 `references/acceptance-metrics.md` §8。

## 三、一次完整迭代的形态

给"改片"这件事一个节奏感：**每一轮只改少数几件事，每件都要有反馈来源和验收数字。**

| 轮次 | 触发（反馈） | 改了什么 | 验收 |
|---|---|---|---|
| v16 | "之前素材是咋挑的啊" | ① 某一章**逐帧看图重挑**；② 照片改成排在"同一时段的视频之后"；③ 标题压条硬边→31 级渐变；④ 逐镜稳定化 + 全场轻裁 1.08 | 抽帧确认新素材在片内且顺序对；压条过渡连续；单镜 A/B 对比稳定化 |
| v17 | "有水流声的保留原声" + "感觉有点碎" | ① 原声清单按**实际窗口**重定（+ 修两个缓存键漏洞）；② 短版正文 15 条 → **12 条** | 原声分档表；镜长中位 7.0s → **10.0s**；量分段电平证明原声生效 |
| v18 | "短版升为主打 / 剪两个素材区别大的版本 / 字体用思源 / 开车素材太差" | ① A/B 两版由选片驱动；② 中文字体改思源家族名；③ 车拍统一裁底 18%；④ 取消"章节封面"概念 | 三个文件 `-f null -` **0 错误**、音频 mean ≈ −19.8dBFS；渲一帧确认仪表台消失 |

**方法论**：把"用户一句抱怨"翻译成一个**可量的指标**，改完再量一次。

```
"有点碎"             → 正文中位镜长
"听不见原声"          → 分段 mean_volume
"上半部分颜色不一样"   → 逐行亮度阶跃
"糊"                 → 拉普拉斯方差
"音乐里有人念白"       → ASR + 音节速率调制
```
