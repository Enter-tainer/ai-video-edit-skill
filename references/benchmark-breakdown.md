# 拆解对标视频：把"感觉"量成数

> 面向对象：另一个 agent。每条尽量写成"**量什么 / 怎么量 / 量出来怎么判**"。
> **本文件不含任何对标视频的原始脚本、逐镜分镜表、台词原文、作者名、标题或链接**——
> 那是别人的内容，公开仓库里贴原文有版权与署名问题。这里只有**方法论**与**抽象后的统计结论**。
>
> **证据标记**（沿用 [`provenance.md`](provenance.md) 的分层）：
> `✅` = 本仓库有源码/实测数可复算；`③` = 来自当时的拆解记录（原始分镜表未随仓库分发，
> **不可独立复算**）；`⚠️` = **未核实**，不要当事实用。
>
> 配乐部分的专题展开在 [`music-and-score.md`](music-and-score.md)；
> 选片与详略预算在 [`selection-and-structure.md`](selection-and-structure.md)。

## 一、为什么要拆对标：不是抄，是把"感觉"变成可量的数

不量化的话，剪辑决策全是主观的——"感觉有点碎""音乐有点抢""没有高级感"，
每一句都无法验收，改完也不知道好没好。

拆对标要拿到的是三样东西，**都不是"别人的做法"**：

1. **同类片子的正常值**（基线）。知道 19–27 分钟的长片冷开场只占全片 2–4% ③，
   比自己拍脑袋定 30 秒有用得多。
2. **能力缺口的清单**。逐条比"他们有 / 我没有"，库存为 0 的那几行就是下一次拍摄的**补拍清单**
   （见 §五）——这是拆对标最容易被忽略、但复用价值最高的副产品。
3. **一个形态判断**：你和对标**是不是同一个物种**。这条判断错了，后面量什么都是错的。

### 1.1 先做形态判断，再谈"照搬什么" ③

**规则**：先量对标片的**旁白覆盖率**（人声时长 / 全片时长）与**留白位置**，再决定照搬什么。

**为什么**：实测一批对标代表作（长片形态）的旁白覆盖率是 **98.5%–100%**——
全程有人说话，留白只出现在**开场冷蒙太奇**与**高潮/延时段**。
如果自己那一版是**纯音乐无旁白**，它在形态上属于"预告片 / 精华片"，
**不是同一个物种**——直接照搬镜长与结构必然错位。
正确处置：叙事版按叙事版的标准定，纯音乐版按预告片的标准定，**两版分开定标准**。

**怎么验证**：ASR 逐段转写 → 按"有人声的秒数"求和 → 除以全片秒数；
把留白段标在时间轴上，看是不是只有"开场 + 高潮"两处。

> ⚠️ 覆盖率 98.5%–100% **没有公开的覆盖率计算脚本**，是当时逐条 ASR 听译的汇总口径；
> 换一批对标片必须重算。

## 二、拆什么、怎么量（可执行清单）

### 2.0 先定样本与口径

- **样本量**：当时一次拆 **8 条代表作** ③。8 条**不是统计总体**，
  它给的是**量级与形态**，不是分布。不要说"对标片都是这样"。
- **三条独立的数据线**，必须共享**同一套时间码**，否则对不起来：
  **画面**（分镜表）｜**声音**（ASR 转写 + BGM 扒谱）｜**结构**（时间轴上标注段落）。
- **口径先写死**（这是最容易出错的环节）：
  - 静帧照片 / 滚屏卡**算不算**镜头？（本仓库 [`scripts/shot_stats.py`](../scripts/shot_stats.py)
    的做法：**不算**，`photo` / `card` 行直接跳过，否则会把中位数拉低 ✅）
  - 片头片尾算不算进"正文"？
  - 用**平均值**还是**中位数**？
  - 素材时长用**原始素材全长**还是**成片里实际使用的那一段**？（见下）

### 2.1 镜头时长分布（性价比最高的一项）

**量什么**：均值、**中位数**、最短/最长、分档占比（`<1s` / `1–3s` / `3–5s` / `5–8s` / `≥8s`）、
**`≥8s` 的镜数**。

**怎么量**：

1. 场景检测切出分镜表，或直接用入出点表，导出每一镜的时长；
2. 按 **开场 / 正文 / 片尾** 分组统计，**不要全片混算**；
3. 出分档直方图 + 中位数。

**为什么不能只看全片平均**：平均数会被开场那几刀快切和个别超长镜带偏。
这个坑我们在自己的片子上实测踩过 ✅：一开始只是把每条镜头**稍微拉长一点**，
正文中位只从 **7.0s** 动到 7.0s（长版是 6.0s），**"碎"根本没解决**——
因为总时长固定时，单条拉长必然要靠别处补回来。
正确的做法是**减少镜头数**：正文从 15 条收到 12 条，中位才从 **7.0s → 10.0s**、
`≥8s` 的镜数从 7 → 9 ✅。
所以**中位数和"长镜条数"才是判据，平均只是参考**。

**只看"实际使用窗口"**：凡是"素材 → 成片"的量（镜长、音频电平、BGM 峰值位置），
**一律按"成片里真正用的那段窗口"重算**，不要用整条素材/整首曲子的全长。
理由与配乐侧的实证见 [`music-and-score.md`](music-and-score.md) §1.1：
一首曲子自身的峰值位置，和它在成片里听起来的位置可以差很远——
只取前 30 秒时，曲内 0.73 处的峰值根本不在这 30 秒里，
**不按窗口重算就会把"峰值偏晚"读成"没问题"** ✅。

**对标实测（抽象后）** ③：

| 量 | 实测值 |
|---|---|
| `>5s` 的镜头占比 | **63.1%** |
| `<1s` 的碎镜 | **没有**（只在其中一支对标片里观察到，单样本） |
| 平均镜长区间 | **5.6–10.2s** |

**判据**：先算自己的"**正文中位镜长**"与"**`≥8s` 镜数**"，再和目标比。
**不要**只看平均镜长落没落在区间里——那正是上面那个坑。

### 2.2 结构骨架

**量什么**（每一项都要一个秒数或百分比，不要形容词）：

1. **冷开场多长 + 占全片百分比**；
2. 开场里有**几刀**、每刀多长（快切占比）；
3. **章节切点**在第几秒、每章多长；
4. **高潮**在第几分钟、前后各章多长；
5. **结尾**多长、有没有一次独立的黑场落版。

**怎么量**：把成片时间轴按段落标注（章节卡、音乐换段、地形/场景切换三处取交集），
再把上面 5 项排成一行看。

**对标实测** ③：8 条代表作时长 **19–27 分钟**，
冷开场 **30–90s ≈ 全片 2%–4%**。

**一条被数据支持的开场骨架** ③（当时标注为"照搬对标拆解得出的硬规则"）：

```
钩子长镜（**1 条**，不出现人物，零旁白）
  → 大景蒙太奇（**15–50s，1–3s/镜**）
  → 标题条叠在实拍上（不切黑场）
  → 报数字（数据卡 / 信息浮层）
```

**结构自检** ✅（来自本仓库的实战教训，比对标片同样适用）：
把"**各章实长**"排成一行，看**过渡章是不是比高潮章还长**——
这是最常见的结构错误。历史上真的出现过一次：过渡章 **39.6s** 比高潮章 **23.6s** 还长。

**结尾长度**：⚠️ 本次取材里**没有可核实的对标结尾时长数字**（没有"结尾必须 N 秒"的判据）。
自己量：结尾段时长 / 全片时长，以及结尾是不是只有一处黑场。

### 2.3 花字 / 字幕的"克重"与位置

"克重"不是一个现成的量，建议拆成**四个可数的量**（⚠️ **这组口径是本仓库新提出的，
没有已验证的阈值，不要拿它当判据**）：

| 量 | 怎么量 |
|---|---|
| **出现频次** | 花字/标题条条数 ÷ 片长（分钟） |
| **单条信息量** | 每条字数 + 行数 |
| **屏占** | 文字包围盒面积 ÷ 画幅面积 |
| **停留时长** | 每条的 enable 时间窗（秒） |
| **位置** | 上 / 下、居中 / 偏侧、有没有压在主体或人物脸上 |

**已核实可用的观察** ③：

- 某条对标片**全片只有 1 处标题条、0 花字**；
- 数据浮层约**每 5–8 分钟 1 个**；
- 数据卡 / 里程卡是**叠在实拍上**的，不是切黑场做全屏卡 + 缓推放大
  （全屏数据卡 + 缓推放大观感"确实廉价"，已从我们自己那版删掉）。

> ⚠️ **"花字越多越掉高级感""文字只承担地点/海拔/时间/评价四件事""撤旁白 ≠ 放慢"**——
> 这几个说法在取材到的源码、实测记录与方案文档里**只有结论、没有算法/脚本/对照组**。
> 要用只能当**假设**，并先写出验证方式（例如"花字越少越高级"→ 同一段加 / 不加花字
> 各出一版让人盲选）；**验证之前不要写进流程当硬规则。**

### 2.4 口播 / 旁白怎么处理

**量什么**：① **覆盖率**（有人声秒数 ÷ 全片秒数）② **留白位置** ③ **各段语速（字/分）**
④ 有旁白处的**画内切点数**。

**怎么量**：ASR 逐段转写（要带时间戳）→ 按段落求和 / 数字数 → 得字/分。

**对标实测** ③：

| 量 | 实测值 |
|---|---|
| 旁白覆盖率 | **98.5%–100%**（长片形态） |
| 语速 · 行程交代类 | **219 字/分** |
| 语速 · 爬升类 | **75 字/分** |
| 语速 · 到达类 | **34 字/分**（最慢） |
| 留白位置 | 只在**开场冷蒙太奇**与**高潮/延时段** |

**判据**：

- 把"有旁白"的镜头单独列出来，**画内切点数应为 0** ③
  （对标片有**单镜 106s**、**一镜到底 191.6s** 的实例）；
- 语速按段落类型分档检查：**到达段超过 ~50 字/分就是没压下来**；
- 自用补录口径：**120–140 字/分、每段 60–150 字**（这是"能听清"的区间，不是对标实测值）。

### 2.5 音乐怎么铺

**量什么（六个量）**：**调性 / 和弦 / BPM / 音符密度（音/分）/ 长音占比 / 曲式**。
音频侧再加：**能量峰值位置、动态范围、声场宽度、谱平坦度**。

**怎么量**：扒谱拿前六个量 → 本地 `ffmpeg` + `numpy` 算音频侧四个量 →
**把曲子映射到成片里的"实际使用窗口"再重算峰值位置** → 摆在一起反推槽位配方 →
按配方生成 → 把生成曲丢回扒谱看有没有落回目标（闭环）。

**这一节不在这里展开**：算法、三档槽位配方、生成与回读验收的完整做法见
[`music-and-score.md`](music-and-score.md) §1。这里只记两条**属于"拆解"本身的**口径：

1. **必须按使用窗口重算**（同上 §2.1），不是按整首曲子；
2. **拆解只能用来"读配方"，不能拿旋律去生成发布物**——
   这类扒谱/作曲权重常是 **CC-BY-NC-4.0（非商用）**，用商用曲库的旋律做发布物是许可问题。

## 三、拆完怎么用：映射到自己的片子，得出"改哪几刀"

拆完对标**不等于**照着改。落地是四步：

1. **先量自己**。用与对标**完全相同的口径**把自己的成片量一遍（同样分组、同样看中位、
   同样按使用窗口）。口径不一致的对比没有意义。
2. **逐项列出差值，只输出"改哪几刀"**。不要输出"我们的结构要更像对标"这种话。
   每条改动要写成**可执行动作 + 验收数字**：

   ```
   "感觉有点碎"          → 正文中位镜长           → 减少正文镜头数（不是把每条拉长）
   "音乐有点抢"          → 音符密度（音/分）        → 把密度压进配方区间，不是把音量调小
   "没有高级感"（⚠️ 不可量） → 先定义成可量的量，再改
   ```

   完整的"抱怨 → 指标"映射表见 [`selection-and-structure.md`](selection-and-structure.md) §三。
3. **不要直接套绝对秒数**。对标的绝对秒数是在**对标的片长**下成立的。
   正确做法是**先按比例算，再判断"这点时间够不够装内容"** ③：
   对标冷开场占全片 2%–4%，按比例套到 5 分钟片就是 **6–12s**——
   但那点时间**连"标题 + 数字"都塞不进去**。实测 **81s 太慢、30s 仍偏慢、
   20s 是三件事（给第一印象 / 上标题 / 报数字锚点）都能做完的最短长度**。
4. **能力缺口用"结构等价的镜头"补，不硬凑** ③：

   | 对标有 | 你没有时的替代 |
   |---|---|
   | 航拍大全景 / 升高 | 前景框景（树枝 / 经幡 / 门框 / 帐篷口）+ 4K→1080 裁切出 2× 伪长焦 + 人极小比例镜 |
   | 固定机位延时 | 静止空镜放慢 + 缓推（**并列入下次必拍**） |
   | 对镜口播 | 后期旁白 + 花字 + 拟声 |
   | 地图 / 数据动画 | 用轨迹点算出里程 / 爬升 / 海拔剖面，做成数据卡 |

   注意第 1 行：**换一个结构口径，同一批素材的价值会翻转**——
   一批被判"低价值"的贴地特写（如低头看路的脚与杖），
   恰恰是对标"**每 40 秒一个障碍**" ③ 的节奏镜头，换口径后重新启用。

## 四、几条反直觉但被数据支持的结论

| # | 结论 | 为什么反直觉 | 数据 | 等级 |
|---|---|---|---|---|
| | ↑ 第 **1–5** 条是最早那批；第 **6–18** 条是把同一次拆解（对标改版记录 ＋ 配乐体检）里**其余**被数据支持的结论补全。**没有数据支撑的另见 §四之二。** | | | |
| 1 | **不是"3 秒一切"** | 短视频语感让人以为越碎越"高级"、越抓人 | `>5s` 的镜头占 **63.1%**；没有 `<1s` 的碎镜；平均镜长 **5.6–10.2s** 都算正常。快切只放**开场 / 换地形 / 片尾**三处 | ③ |
| 2 | **口播 / 独白时绝不切画面** | 与"保持节奏、别让画面停住"的常识相反 | 对标有**单镜 106s**、**一镜到底 191.6s** 的实例；"**低谷不剪，高峰才剪**" | ③ |
| 3 | **开场时长不能按占比套** | 按比例算（2%–4%）看起来最"科学" | 按比例得 6–12s，但装不下"标题 + 数字"；实测 **81s 太慢 / 30s 偏慢 / 20s 才够** | ③（6–12s 与 20s 都是实测推导） |
| 4 | **换结构口径，同一批素材评分会翻转** | 以为"不好看的素材"就是不好看 | 被判低价值的一类贴地特写，换成"每 40 秒一个障碍"的节奏口径后变成必用镜头 | ③（"每 40 秒一个障碍"本身 ⚠️ 不可复算） |
| 5 | **"音乐抢"是密度问题，不是音量问题** | 第一反应是把音乐调小 | 垫底类配方的音符密度是 **16–35 音/分**，实测自己的曲子是 **228 / 126 音/分**（配方的 4–7 倍）；密度压下来之后就不抢了 | ✅（算法与实测数见 [`music-and-score.md`](music-and-score.md) §1.2/§1.3） |
| 6 | **先判"是不是同一个物种"，再谈照搬** | 拆对标的第一反应是"抄结构、抄镜长" | 对标长片旁白覆盖率 **98.5%–100%**，留白只出现在**开场冷蒙太奇**与**高潮/延时段**；自己那版是**纯音乐无旁白**，形态上属"预告片 / 精华片"——照搬镜长与结构必然错位。处置：**叙事版与预告版分开定标准** | ③（覆盖率数字本身 ⚠️，无计算脚本） |
| 7 | **"缺最贵的那个镜头"不等于片子立不住** | 航拍大全景是这类片子的招牌，库存 **0 条**看着就是硬伤 | 用"结构等价的镜头"替代：前景框景（树枝 / 经幡 / 门框 / 帐篷口）＋ 4K→1080 裁切出 2× 伪长焦 ＋ 人极小比例镜；一版 **81s 开场样片**已经渲染出来，验证"没有航拍也能立住开场" | ③ |
| 8 | **你不缺的那一项，可能正是对标最吃的** | 审计前总以为缺口在"设备 / 技术" | 逐条点算库存：**背影跟拍 38 + 13 条**，而这正是对标最吃的一类；反过来"感觉上有"的类别点算下来可能是 0。**审计要逐条点数，不看感觉** | ③ |
| 9 | **旁白语速要按段落类型分档，不是全片一个语速** | 语速通常被当成"全片统一的风格参数" | 对标实测：行程交代 **219 字/分**、爬升 **75**、**到达 34（最慢）**；自用补录口径 **120–140 字/分、每段 60–150 字**，到达段压到 **30–40 字/分** | ③ |
| 10 | **"音乐抢"往往只有一项指标错，不是整体不行** | 听感上觉得"配乐全都不对" | 逐轴对表：三首曲子的**调性 / 和弦 / BPM 全部踩在配方上**（60 BPM、i–VI–VII、I–V–vi–IV），唯一偏离的是**音符密度**（228 / 126 音/分 vs 配方 16–35）→ **体检要逐轴对表，不要整体否定** | ✅（算法与实测数见 [`music-and-score.md`](music-and-score.md) §1.2/§1.3） |
| 11 | **可量化的要求写进提示词没用，必须写进谱面** | 以为"把要求写得更细，模型就更听话" | 同一段：提示词里明写 `Eb 大调 / I–V–IV–I / 49–61 音/分` → 生成 **G 大调 / C–Em7–D / 124.2 音/分**（三项全废）；换成**手写 ABC**（明写 `K:` ＋ 和弦内联 ＋ 音符数自己数得清）→ **Eb:major / Eb–Bb–Ab–Eb / 53.1 音/分**（三项全中） | ✅（对照实验，见 [`music-and-score.md`](music-and-score.md) §3.1） |
| 12 | **"峰值偏晚"可能只是量错了窗口** | 峰值位置看起来是个客观量，量了就是量了 | 曲子自身的峰值位置 ≠ 它在**成片里**听起来的位置：一段只取曲子的前 30 秒时，曲内 0.73 处的峰值根本不在这 30 秒里。按"使用窗口"重算才看到真相：开场曲段内峰值 **0.37–0.59**（偏晚，配方要 0.10–0.33），片尾曲线折算全片 **0.886** ✓ | ✅ 算法 · ③ 数值（见 [`music-and-score.md`](music-and-score.md) §1.1） |
| 13 | **纯器乐也会"说话"：只写 `no vocals` 不够** | `instrumental=true` 就以为里面没有人声 | 出问题那段 **3–6Hz（音节速率）调制 16.19%**，其余段只有 **0.57%–5.91%**，且 ASR 从里面**转出一整句英文** → 音色里混进了**类人声的垫子**（颤音 pad / 类合唱）。把 `NO_VOCAL` 说死 ＋ 同 seed 重渲 → **0.93%**、ASR 变空 | ✅（算法与常量在源码，见 [`music-and-score.md`](music-and-score.md) §4.2） |
| 14 | **定案靠"离群 + 第二条独立证据"，不靠绝对阈值** | 总想找一个阈值，比如"调制 >10% 就是人声" | 修后 **0.93%**、其余段 **0.57%–5.91%**，而一条**不是**人声的对照曲也到了 **9.85%** → 没有干净阈值；**16.19% 是离群 ＋ ASR 转出连贯句子**，两条同时命中才定案 | ✅ |
| 15 | **成片复验时"调制升高"不一定是人声** | 复验数字比素材段高一截，就以为又混进人声了 | 成片复验某段 **8.26%**（确实比该段素材侧高），但 ASR 为空 → 那段混了**脚步 / 呼吸等同期声原声**。所以**成片复验要结合"这一段有没有留同期声"一起看** | ③ |
| 16 | **曲子比段落短 2 秒不是小事** | 差两秒，以为交叉淡化能糊过去 | 铺床函数在曲子末尾**静默补零** → 成片里就是一段**真空白**。修法：把本段**收在曲子末尾**，并把**下一段起点提前**，保证相邻两段至少重叠 **1.0s** | ③ |
| 17 | **不是所有电平凹陷都要修** | 接缝判据是"不出现突起 / 凹陷"，那就见凹陷就填 | 实测某处接缝 **−8.8dB** 恰好落在**低谷章**——两边都刻意收着造成的，**保留**；判据只用来抓"不该出现的突起 / 凹陷"，而且要**逐处看语义** | ③（数值） |
| 18 | **合成参考乐床可以先"占位对齐剪辑点"** | 以为得先有曲子，才能对齐配乐与剪辑点 | 先用程序合出一版**非版权参考乐床**（和弦进行 ＋ 脉冲，撞击 / 钟声对齐剪辑点），配着画面把 81s 开场样片做出来，验证结构立得住；之后**直接替换成生成曲** | ③ |

> **反面教材（⚠️ 不要当结论）**："花字越少越高级""撤旁白 ≠ 放慢""某些档位必须用某种强度"——
> 这些**听上去同样反直觉、同样像经验**，但**没有可复算证据**（见 §二 2.3 与 §六）。

§四 表里都是**有数据或算法支撑**的结论。下面这几条来自同一批拆解与配乐体检记录，

| # | 说法 | 为什么不能当结论 | 等级 |
|---|---|---|---|
| 1 | **"i–VI–VII 就等于'史诗感 / 辽阔感'"** | 和弦序列本身可复算，但"某组和弦 = 某种听感"**没有对照实验**（换一批曲子、换配器都没测过） | ⚠️ 未核实 |
| 2 | **"同期声当'底噪'用，下撤段做'声音减法'"** | 只有听感描述：现场环境声"全是风噪、无人声"，所以铺成底噪、下撤段减掉。**没有 dB / 频段 / 覆盖率上的对照数据** | ⚠️ 未核实 |

## 五、补拍清单的方法（拆对标的高价值副产品）

补拍清单不是"想拍什么拍什么"，是**从对标审计表里反推出来的欠件**。

### 5.1 先做一张三列表

| 他们必拍的 | 我的库存（**逐条点算，不看感觉**） | 处置 |
|---|---|---|
| 某类镜头 | 0 条 / N 条（**带具体条数**） | 替代方案 **或** 下次必拍 |

**硬规则**：**库存为 0 的行，必须写出替代方案，否则它就是下一个缺件。**
"处置"列不允许空着——空着的意思是这一条会在成片里变成硬伤。

**为什么"逐条点算"很重要**：同一类镜头，感觉上有，点算下来可能是 0；
反过来一批"原本平均 2 分、被判为低价值"的镜头，点算出来有十几条，
换口径后正好补上对标最吃的那一项（见 §四 #4）。

### 5.2 从对标反推出的可执行补拍项 ③

当时那张审计表直接给出了下面这些**拍摄动作**（都写成"数量 + 条件"，可以直接照做）：

- **对镜口播 20–30s × 每天 1 条**（报目标 / 报数字 / 说感受），**一个机位不切**；
- **每个节点四连拍**：路牌特写 → 报时间的手机/手表屏 → 到达全景 → 节点口播；
- **每个爬升段开头**：脚 + 杖踩过路面的**贴地特写 1–3s**；
- **每天至少 1 条固定机位延时 50–60s**（三脚架，或用石块垫平），**期间不说话**；
- **前景框住远景**：经幡 / 门框 / 帐篷口（这是"替代航拍"最便宜的一招）；
- **每上升 300–500m**：血氧/心率表极特写 2–3s + 报数字
  （对标**每 5–8 分钟 1 个数据浮层** ③）。

### 5.3 清单还要排序

一次拍摄往往只能多补 3 件事，排序依据：

1. **库存 = 0 且没有替代方案**（不补就是硬伤）→ 最高优先；
2. **单位成本最低**（例如"前景框景"几乎不额外花时间，却能顶掉一整个航拍缺口）；
3. **一次动作能覆盖多个缺口**（"节点四连拍"同时补了信息特写、报数字、口播三项）。
