**四个硬规则**

1. **平均镜长砍到 3–5 秒**（另两家 5.5–10.2 秒），且**几乎没有 1 秒碎镜**（<1s 只占 3–8%）。
   也就是说它快，但快得有"重量"——不是靠糊碎镜，是靠**大量 3–4 秒的常规镜**。
2. **均值永远大于中位数**（4.24 vs 3.57）：结构是"**大量 3–4s 常规镜 + 少量 8s+ 长口播/航拍**"。
   维持手段是**硬切**（女巫全片 560 个切点几乎全是硬切，只出现 1 处黑场转场）；
   镜头内部运动（航拍推进、手持跟随）只提供 1–2 秒"呼吸"，**不承担节奏**。
3. **快切换挡位，不是全程快**：
   - 波峰（≈25 镜/分钟）：开场蒙太奇、店铺/集市逛拍、仪式群像、结尾抒情蒙太奇
   - 波谷（6–11 镜/分钟）：双人访谈、剪影空镜、教堂/长镜抒情
   - 女巫：最快 3 分钟窗口 57 镜（15 分仪式段），最慢 19 分仅 25–26 镜（≈7s/镜的采访段）
   - 淘金：最快的一分钟是 **第 0 分钟 45 镜**，最慢是第 2–4 分钟（11–14 镜/分）
   - 日食：结尾 22–23 分钟 **1 镜/分钟**（一镜到底看日全食）
4. **开场看题材下菜**（这是它和 vlog 最大的不同）：
   - 调查/猎奇类 → **快切蒙太奇砸信息**：淘金开场 30 秒 **35 镜**（≈0.86s/镜）
   - 人物/仪式类 → 中等：女巫开场 30 秒 8 镜（先 6 个 ≤1.8s 快切立钩，第 8 秒落长镜口播）
   - 自然/风光类 → **长镜压场**：水下风暴、挪威开场 30 秒只 **4 镜**

## 三、结构：三种长片模板（都能照抄骨架）

### 模板 A｜调查纪实（女巫 39:37、淘金 22:24、赌场 53:49）
> **钩子（由头/赌注）→ 三段式提问立主题 → 线性亲历 + 逐环举证 → 多人物接力 → 元反转 → 主题金句升维 → 收尾**

- 女巫：0:00–0:13 钩子（100 万支票 + "小心诅咒"）→ 三段式提问立主题 → 探访女巫/顾客/政客/罗姆女孩
  → **元反转（翻译造假）** → 36:39–38:33 主题金句收尾（"理性不能回答所有的痛苦""她是否还有离开的自由"）
- 淘金：0:00–0:24 钩子（"应该没有人会不喜欢黄金，对吧？"先认同再反转）
  → 每环用"**本该规范却失序**"定式句串联（"讲道理，这应该是最讲专业、最凭规范的一步，但在这里，则完全不同"）
  → 19:16–20:36 结构归因（教育/土地改革/制裁/恶性通胀）→ 宿命式收尾
- **写法特征**：旁白句长 15–35 字、大量"但/而"转折咬合段落、**无网络语无自嘲**（与徒步 vlog 的口语化完全相反）、
  金句集中在**每段收口**与**最后 3 分钟**。

### 模板 B｜样片日记（水下风暴 24:47）
> **"我们打算拍到 X" 立任务 → 拍摄过程本身成为叙事（设备/天气/失败）→ 自然奇观段撤旁白 → 尾声**

### 模板 C｜体验旅行（挪威 28:24、西班牙日食 24:33）
> **资讯/体验型文案**（语速 219–246 字/分，全对标集最快）→ 事件高潮（日全食）→ 见闻总结

**语速对照（同一件事的三种讲述强度）**：影视飓风 137–247 字/分（挪威 246 最快）｜
Links 110–204｜呆呆 123–150。**语速 = 内容密度**：影视飓风信息型段落几乎不停嘴，
用画面扛节奏；Links/呆呆靠长镜和留白扛节奏。

## 四、分镜：可复制的镜头序列

**开场钩子（3 种，按题材选）**
- 快切版（淘金）：35 镜/30 秒，`航拍大景 → 人群 → 手部特写 → 工具特写 → 地面细节`循环，先砸信息
- 倒叙版（女巫）：0–8s 6 个 ≤1.8s 快切（支票→合影→击掌→查资料）→ 第 8s 落**固定机位长镜口播**立命题
  → 22s 切暗场仪式画面 + 外语咒语字幕制造神秘感 → 0:40 标题卡进正题
- 长镜版（自然类）：4 镜/30 秒，一镜到底建立环境

**正片循环（女巫）**：`空镜特写 → 手持跟随主角背影 → 群像全景 → 双机采访`
随后**每个换段都用"航拍大远景 + 屏幕红字地点标题卡"**（1:16、16:15、33:00 三处）。

**几个固定动作**
- 采访段：**双机正反打**（单人近景 + 双人全景），每 20–30 秒插一段空镜
- 人物出场：**人物名条**（"KAL…ANDRA / 女孩 Andra" 16:05）
- 章节切换：**中英双语标题卡**（"女巫 / THE WITCH" 0:40；"罗马尼亚 / ROMANIA" 1:16）
- 抒情结尾：`群像张臂 → 生活细节特写（猫/水果摊）→ 黑场 → 主创演奏 outro`（3–5s/镜，多镜无字幕）

## 六、包装与字幕

- **字幕**：画面底部居中、白字无底框，**常驻**（女巫语音覆盖 92.1%）；外语受访段用**双语两行**
- **花字/标题卡**：章节中英双语标题卡、人物名条、信息花字（"注意 / 驱赶与看守"）
- **地图/进度图标**：基本不用（地点全靠标题卡 + 航拍交代）——这点和 Links 的"海拔浮层"路线不同
- **片尾滚屏**：**双栏**（左「音乐 Music」右「音乐版权」）+ 器材列表 + 素材鸣谢，压在一段混剪 B-roll 上

## 七、哪些能抄、哪些抄不了（给主人的落地判断）

**能抄（一人一手机也能落地）**
1. **平均镜长砍到 3–5 秒 + 硬切为主**：把"3–4 秒一镜"当默认值，只在口播/访谈时放到 8 秒
2. **快切波峰/长镜波谷的挡位思维**：开场与换段快切（每分 20–25 镜），访谈/抒情段慢下来（每分 6–10 镜）
3. **开场钩子分题材**：徒步风光片学"4 镜长镜压场"或"8 镜中等"，**别学 35 镜快切**（那是调查片的信息密度）
4. **每段换场用"航拍大远景 + 地点标题卡"**：这是最便宜的"制式感"
5. **段落收口金句**：每段最后一句给一个结论句，全片金句压在最后 3 分钟
6. **双语/地点标题卡 + 人物名条**：花字只在章节切换点出现（3–4 处），别满屏花字
7. **片尾用一首大曲子 + 一段连续画面 + 收束字幕**（见 BGM 报告的收尾模板）

**抄不了（需要团队/预算，别硬学）**
1. **定制配乐**（孙嘉伟）+ 专业声音设计/混音岗位——个人可用商用曲库替代
2. **双机采访 + 编导现场调度**（怀谷在片中是主持人角色，有访谈能力）
3. **8 条/月的产能**——机构化运营，个人按 2 条/月规划更现实

## 八、逐片要点（已拆完的 4 条）

**《女巫》39:37**（561 镜 / mean 4.24s / 开场 30s 8 镜）

**《水下风暴》24:47**（350 镜 / mean 4.25s / 开场 30s 4 镜）
- **自然段不比人物段慢**：企鹅段 3.68s ≈ 口播段 3.67s；真正慢的是**水下/鲸豚段**（>5s 占 39.8%，mean 5.58s）
- 镜头占比估计：航拍 25% / 长焦 15% / 水下 10%
- **78 秒无旁白段（17:40–18:58）** = 26 镜快切（mean 2.80s）航拍风光 + 地名标题条串联——**撤旁白时反而切得更快**
- 结构：倒叙钩子（成片结果前置）→ 线性"拍摄日记"多地点拼盘 → 每段「现场反应 + 知识/段子旁白 + 无旁白样片蒙太奇」三件套循环 → 好望角金句收尾
- 片尾 **4 栏滚屏**；语速 246.8 字/分（全对标最高）靠"旁白讲清楚 + 同期声好玩"双层语速

**《非洲淘金》22:24**（409 镜 / **mean 3.29s、中位 2.77s，全对标最快**）
- **开场 30 秒 35 镜（0.86s/镜）、第 0 分钟 45 镜**，42 秒进正题——调查片的"信息砸脸"式开场
- 分档：**访谈按句切 2.6–3.8s**｜空镜/作业段 4–5s｜钩子与冲突段 0.5–1.5s 碎切
- 镜头序列：`采访=双人全景 → 受访者近景 → B-roll 特写×2 → 回近景`；
  `井下作业=低照度剪影全景 → 手持跟随中景 → 工具特写 + 黄色科普花字 → 记者反应近景`；
  `收尾=人物中景 → 空镜符号 → 航拍拉升`
- 语速 124.1 字/分（全对标最低）**不是留白**，而是旁白让位于英文/绍纳语同期声采访（"把话筒交给当事人"）
- 片尾 22:12 起滚屏，**音乐栏 16 首**

**《西班牙日食》24:33**（306 镜 / mean 4.82s / 开场 30s 16 镜 / 结尾 30s 1 镜）
- 开场：0.9–2s 预告快切 + 器材特写 + 主题剪影点题；正片是 `大全景 → 人物中景 → 反应特写 → 对镜口播` **四拍循环（3–5s/拍）**
- **事件高潮段改三机位长镜交替（8–15s/拍）**：长焦太阳特写 / 广角湖面远景 / 手持人物反应，20:00–21:21 实时长镜，**未用延时**，靠"湖面 + 风车"前景踩点
- 片尾 1434–1473s：淡出 → **单条连续日食长镜** + 滚屏字幕（**演职员 4 栏 / 音乐 2 栏 / 设备通栏**）
- **彩蛋**（我抽帧核实过 t=1459）：**「特别鸣谢 / SPECIAL THANKS」第一行就是 Linksphotograph**（同列还有中国Boy-Hans、飓风男装、巡天者叶梓颐）——两家对标对象在同题材上互相致谢

**《赌场的秘密》53:49**（796 镜 / mean 4.06s / 全对标最长长片）
- **8 大幕，每 2–4 分钟用一句"显式设问句"换场**（"这是为什么呢？""那下班后呢？""真的更好了吗？"）——
  这是它撑住 53 分钟的**核心机制**：不是靠新场景，是靠**设问接力**
