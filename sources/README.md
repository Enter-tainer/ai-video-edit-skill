## 使用注意

1. **这些是第三方材料，版权归原作者**。引用其结论/数据时请**标明出处**（哪份报告、哪支片），
   不要把 up 主的观点写成自己的结论。仓库只做"引用与索引"，不主张对这些内容的权利。
2. **报告里的结论不等于事实**。`references/benchmark-breakdown.md` 已把每条结论标了证据等级
   （`✅ 可复算` / `③ 当时的拆解记录（不可独立复算）` / `⚠️ 未核实`）——**读原始报告时要带着这个分级看**。
   例如"花字越多越掉高级感"这类，原始报告里也只有结论、没有对照组。
3. 报告里的平台 UID、粉丝量、播放量等元数据是**抓取当时**的值，会随时间变化。
4. 链接失效时这些文件就是存档；要更新请重新抓取，并在提交信息里写明日期。
