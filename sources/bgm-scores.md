# 对标 BGM 的谱面级分析（SheetSage2 扒谱）

上一版 BGM 报告只做到"是什么曲子"（Shazam + 简介曲表 + 片尾滚屏）。
这版用**本地 SheetSage2 扒谱**（`scoresage2-api` :8101）把识别出的 BGM 段落转成可编辑谱，
拿到**调性 / 速度 / 和弦进行 / 旋律音域 / 音符密度 / 曲式**——也就是"要复刻这种听感，配方是什么"。

- 取样：**21 个片段**（覆盖三家、按剪辑槽位分层：开场 / 铺垫 / 中段 / 收尾 / 古典 / 爵士）
- 每个片段取自 Shazam 命中的无旁白窗（BGM 露出来的位置），时长 33–50 秒
- 转谱速度：**每段 1.2–2.6 秒**（远快于实时），峰值显存 3.4GB
- 产物：`score.abc` / `chords.mid` / `melody_instrumental.mid` / `events.json` / `key.lab` /
  `chord.lab` / `beat.lab` / `structure.lab`；原始数据在
  `~/projects/bgm-analyze/scores_summary.json`（逐段）+ `scores/<name>/`

### 谱面侧（SheetSage2 产物里就有，之前只用了和弦）

| 维度 | 来源 | 实测范围 | 怎么用 |
|---|---|---|---|
| **和弦变换速率** | chord.lab 相邻时间差 | 平均和弦 **1.4–3.7 秒**（爵士/香颂 42 和弦/分最快，Links 铺垫 16.8/分最慢） | 控制"和声推进速度"，和 BPM 是两个独立参数 |
| **长音比例** | melody_*.lab 音符时长 | Links 铺垫 **0.95**（95% 音符 ≥1 秒）↔ 爵士/香颂 **0.01–0.06**（几乎没有长音） | 织体类型：长音垫 vs 短音流动 |
| **级进/跳进比** | 相邻音程 | 收尾类级进 **0.69**（旋律平滑）↔ 铺垫类 0.38 | 平滑 vs 棱角 |
| **乐句长度** | 音符间隔 ≥1.2 秒切句 | 世界音乐 1.6 秒 ↔ 爵士/香颂 12 秒 ↔ 呆呆 **26 秒** | 越短越"循环感"，越长越"叙事感" |
| **在拍率** | 音符起点 vs beat.lab | 0.40–1.00 | 节奏规整 vs 自由速度 |
| **拍号 + 弱起落点** | rhythm_events.lab | 2/4、4/4 起拍位置分布 | 律动型（前后半拍侧重） |

| **曲式段** | structure.lab | 如 44.8s 的 chorus 段 | 段落边界 = 剪辑换曲点 |

### 音频侧（librosa 直接算源音频，和弦之外的另一条线）

| 维度 | 实测范围 | 最有用的读数 |
|---|---|---|
| **能量峰值位置**（0=开头 1=结尾） | 0.10–0.96 | **收尾/升华类 0.75–0.96**（最后 4–10 秒才到顶）：Evermore 0.96、Old Man Voll 0.96、The Moon 0.80、evergreen 0.79、Tree House 0.75；**开场/爵士类 0.10–0.33**（开场即高） |
| **动态范围** | 6.1–19.6 dB | >13 dB 的段落才是真有起伏（Evermore 6.1 说明对比小、靠和弦推进） |
| **谐波/打击比** | 0.41–0.97 | Old Man Voll 0.41（打击/瞬态多）↔ Folklore 0.97（纯弦乐）→ 织体是"弦乐型"还是"打击型" |
| **立体声宽度**（side/mid） | 0.12–1.18 | 香颂 0.15（老录音、窄）↔ Folklore 1.18（极宽）→ 影响"电影感"的包围度 |
| **频谱重心 / 起音密度 / 静音占比** | 重心 + 起音 85–374/分 | 明亮度与密度 |

**本批最有用的一条**：`能量峰值位置` 把"由弱到强"量化了——
**收尾/升华类片段的能量峰值落在片段最后 4–10 秒（0.75–0.96），而开场类和爵士类是开场就到顶（0.10–0.33）**。
这条可以直接当生成/剪辑的验收指标：生成的收尾曲，逐秒能量曲线应该在结尾才到峰值。

### ⚠️ 音频侧的口径问题（必须先看）

我对 21 个片段逐个跑了 ASR 做质检，结果：**只有 3 段是纯音乐**
（Links《孤岛》Folklore、Links《孤岛》Overlook、飓风《日食》Tree House），
**其余 18 段都有人声压在 BGM 上**。所以：

1. **谱面侧指标（调性/和弦/旋律）相对可靠**——语音没有稳定音高，不会大量变成音符；
2. **音频侧指标（人声带能量、起音密度、动态）会被旁白污染**，上表的"人声带 300–3400 Hz 占比"
   对含旁白片段是"人声 + 音乐"的混合值，**不能直接当"BGM 中频占用率"用**；
3. 顺带一个副产品结论：三家的"纯音乐窗口"很少（21 段抽样里 3 段），且都在**片尾或蒙太奇段**
   ——再次印证 BGM 的主要任务是**垫底**，不是独立欣赏。

**要拿到干净的音频侧指标，正确的下一步是 Demucs 分离人声/BGM 后重算**
（新 uv 项目 + `demucs`，约 2.5 GB 权重；分离后既能算出真实的"BGM 中频占用率/起音密度"，
也能顺便产出各家 BGM 的"纯伴奏"片段供你自己听）。目前环境里没有 demucs，需要先装。

## 二、三个能直接用的结论

### 1. "电影感/显贵"的技术配方：小调 + bVI/bVII 借用和弦 + 60–90 BPM

Links 收尾三首的和弦循环放在一起看：

```
F#m → D  → E  → F#m      (i → VI → VII → i)   Evermore
Am  → F  → G  → Am       (i → VI → VII → i)   Folklore
Gm  → Eb → F  → Gm7      (i → VI → VII → i)   Dreamlife
```

**同一套 `i–VI–VII` 循环，只是换主音**。这就是"史诗感/辽阔感"的来源：
小调主和弦 + **大调的 VI 级和 VII 级**（也就是经常说的"借用和弦"），
听感"悲壮但往上走"，而且**循环极稳定**——不需要复杂和声，一个四和弦循环转两分钟就够。

另一类是"温暖辽阔"（`I–V–IV`）：B→F#→E（evergreen）、C→G→Fmaj7（挪威收尾）；
还有"辽阔又带点神秘"的 `I–bVI–IV`：C→**Abmaj7**→F（Fractured Timeline）——
这个 **bVI 大七和弦**（Ab 在 C 大调里）比普通 IV 级更"高级"，是廉价提升质感的单点技巧。

### 2. 旋律普遍"窄音域、长音、不密"——这是 BGM 能垫住旁白的原因

- 收尾/高潮类的旋律音域 **5–19 个半音**（evergreen 只有 5 个半音，基本是长音铺展），
  只有古典咏叹调（Flower Duet 31 半音）和日系 OST（Old Man Voll 21 半音）才是"宽音域旋律"
- 音符密度 **34–100 音/分**（对比：爵士/香颂类 99–114，世界音乐打击类 267）
- 铺垫类（Links 开场/中段）只有 **16–33 音/分**，两秒一个音——**这才是"垫底不抢"的真正做法**：
  不是把音量调小，是**音符本身稀疏**。

### 3. 槽位--参数对照（照这个填生成参数）

| 槽位 | 调性 | BPM | 和弦 | 音域/密度 |
|---|---|---|---|---|
| 开场冷蒙太奇 | 小调（Gm/Am/F#m） | 60–65 | i–VI–VII 循环 | 窄音域长音，20–50 音/分 |
| 铺垫/讲解垫底 | 大调或小调 | 58–65 | 两个和弦就够（如 Am7–Fmaj7） | **16–35 音/分**，稀疏 |
| 金句/低谷 | 大调（C/Eb） | 60–96 | vi–IV 或 I–V | 钢琴分解，音域 ≤7–19 |
| 高潮→收尾 | 小调 / 大调+bVI | 75–125 | i–VI–VII 或 I–V–IV | 34–100 音/分，弦乐长音 |
| 片尾落版 | 大调 | 75–98 | I–V–IV–I | 49–61 音/分 |
| 纪实/世界段 | 任意 | 107–150 | 短促循环 | 打击层密集（267 音/分）但音域窄 |

## 三、给本地生成器的具体改法（把上面的参数喂进去）

ACE-Step 不吃 BPM/调性参数，但**可以在 caption 里写明调性与和弦**（LM 会读到）；YuE2 直接吃 ABC。

**① ACE-Step 的 caption 追加段落**（在原来风格串后面接上）：
```
... in F# minor, chord progression i-VI-VII loop, slow 60 BPM feel,
sustained string pads, narrow melodic range, sparse arrangement
```
**② 生成后验证**：把生成曲的前 40 秒丢回 `:8101`（`task=full`），看 `key.lab` 和 `chord.lab`
是否落回目标调性与循环——**这是唯一能客观验证"生成曲像不像对标曲"的闭环**，建议纳入批量跑批流程。

**③ YuE2 路线**（要可编辑谱、要指定长度/结构）：用 SheetSage2 扒出的 ABC 做骨架，
`abc_tools.py strip-chords` 去和弦符号 → `run_yue2.py generate --cot melody --abc-file ...`，
风格串换成你的场景（这条链路已在 `yue2-music` skill 里固化为翻唱流程）。
注意穿透到发布层面时，**商用曲库曲目（Musicbed/Epidemic 系）不能直接照搬旋律**——
扒谱在这里的用途是"读出配方"，不是"抄旋律"。

## 四、局限（必须知道，否则会误读）

1. **转录准确率有限**（人声旋律音高类 F1：RWC-Pop 82.5% / Rock 67.1%），和弦识别"领先但不完美"。
2. **片段里混有人声/旁白时结果会失真**：本批有 3 段明显异常
   （库拉岗日 Infinite 只抓到 3 个音、淘金 Exile 无旋律音），已标注作废。
3. **节奏识别受"检测到的拍"影响**：弦乐长音段落容易把拍检成半速（60 vs 120），
   报告里给出的是检测值，判断时按"听觉脉冲可能是两倍"看。
4. **扒谱不等于音乐质量**：`abc_check.json` 只证明 ABC 格式合法，不代表音符真的被还原。
